## 🚀 About This Project

This repository documents my journey of learning and implementing **Cloud Engineering, DevOps and DevSecOps practices** through hands-on projects.

The goal is to understand how modern applications are:

* ☁️ Deployed to the cloud
* 🐳 Containerized
* ⚙️ Automated through CI/CD
* 🔐 Secured throughout the development lifecycle
* 📊 Monitored and maintained
* 🏗️ Provisioned using Infrastructure as Code

> **Learn → Build → Automate → Secure → Deploy**

# 🔐 DevSecOps Approach

Security is treated as part of the development lifecycle rather than something added at the end.

```text
PLAN
 ↓
CODE
 ↓
BUILD
 ↓
TEST
 ↓
SECURITY SCAN
 ↓
RELEASE
 ↓
DEPLOY
 ↓
MONITOR
```

Security practices explored in this repository include:

* 🔑 IAM and least privilege
* 🔒 Secrets management
* 🛡️ Dependency scanning
* 🔍 Static Application Security Testing
* 🌐 Dynamic Application Security Testing
* 🐳 Container vulnerability scanning
* 📋 Security logging
* 📊 Monitoring and alerting
